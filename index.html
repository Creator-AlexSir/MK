Как пользоваться программой

Программа моделирует случайные временные ряды по уравнениям авторегрессии, оценивает коэффициенты методом наименьших квадратов (МНК) и решает системы дифференциальных уравнений методом Рунге–Кутта 4-го порядка — в том числе классическую модель Лоренца.

  1. Введите уравнение модели: например x[t] = a0 + a1 * x[t-1] + wt. Коэффициенты a0, a1, … можно задать в таблице под уравнением.
  2. Если в формуле появляется y[….] или z[….], автоматически открывается уравнение yₜ или zₜ — так задаётся система из трёх моделей.
  3. Задайте длину ряда N, шум δW и начальные условия, затем нажмите «Сгенерировать».
  4. Чтобы оценить коэффициенты по реальным данным, загрузите TXT/CSV/XLSX (колонки x, y, z) и нажмите «Рассчитать».
  5. Результат сохраняется в TXT, CSV или XLSX кнопкой «Скачать». График можно скачать как PNG.

Дискретные модели

xₜ = a₀ + a₁·xₜ₋₁ + a₂·yₜ₋₁ + δWₓ

yₜ = b₀ + b₁·xₜ₋₁ + b₂·yₜ₋₁ + δWᵧ

zₜ = c₀ + c₁·yₜ₋₁ + c₂·zₜ₋₁ + δW𝓏

Коэффициенты подбираются МНК: минимизируется сумма квадратов отклонений. Для каждого уравнения строится своя матрица регрессоров, поэтому система решается по уравнению.

Метод Рунге–Кутта

k₁ = f(t, y)
k₂ = f(t + h/2, y + h·k₁/2)
k₃ = f(t + h/2, y + h·k₂/2)
k₄ = f(t + h, y + h·k₃)
yₙ₊₁ = yₙ + h/6 · (k₁ + 2k₂ + 2k₃ + k₄)

Метод 4-го порядка точности: ошибка на шаге ∼h⁵, глобальная ∼h⁴. В программе доступен и метод Эйлера — для сравнения.

Модель Лоренца

dx/dt = σ(y − x)
dy/dt = x(ρ − z) − y
dz/dt = x·y − β·z

При σ = 10, ρ = 28, β = 8/3 система демонстрирует детерминированный хаос: траектории расходятся экспоненциально, но остаются на странном аттракторе. Нажмите «Рассчитать» на вкладке «Система Лоренца» и повращайте аттрактор мышью.

Форматы файлов

TXT / CSV. Числа через пробел, запятую или «;». Допустима шапка x;y;z. Если колонок три, первая — это x; если есть колонка t или time, она становится осью времени. 

t;x;y;z
0;1,24;0,53;0,11
1;1,31;0,61;0,14
2;1,18;0,58;0,19

XLSX. Первый лист книги, числа в колонках. Шапка — по желанию. Экспорт создаёт такой же файл, который открывается в Excel и LibreOffice.

Обозначения

xₜ — синяя серия yₜ — циановая серия zₜ — фиолетовая серия оценка МНК — янтарная линия загруженные данные — точки δW — случайный шум
