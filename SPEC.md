# SPEC — «Стохастические временные ряды» (MK-main)

Единый контракт для параллельной разработки. Языки не меняем: **HTML + CSS + чистый JS (ES2020)**.
Без сборки, без npm-зависимостей, без внешних CDN. Все скрипты — классические (не модули),
подключаются в `index.html` в порядке: `chart.js`, `io.js`, `rk.js`, `main.js`.

Оригинальные файлы сохранены в `MK-main/_legacy/` (index.html, main.css, main.js).
Файлы `jquery.js`, `jquery.flot.js` остаются в папке, но **больше не подключаются**.

## Файлы и ответственность

| файл | кто | назначение |
|---|---|---|
| `index.html` | Lead | разметка: 3 вкладки, панели, формы |
| `main.css` | Lead | дизайн (сине-голубой + белый) |
| `main.js` | Lead | логика моделей x/y/z, МНК, связывание модулей |
| `chart.js` | chart-dev | движок графиков на canvas (`window.ChartKit`) |
| `io.js` | io-dev | чтение/запись TXT/CSV/XLSX (`window.DataIO`) |
| `rk.js` | Lead | Рунге–Кутта, Лоренц, системы ОДУ (`window.Numeric`) |
| `README.md` | Lead | описание, форматы файлов, запуск |

Вспомогательные (не входят в поставку): `_tests/*` — страницы самопроверки, `_legacy/*` — бэкап.

## Общие правила кода

- IIFE + `'use strict'`, один глобальный namespace на файл (`ChartKit`, `DataIO`, `Numeric`).
- Никаких `alert()` из модулей — только возврат ошибок/`throw`. UI-ошибки показывает `main.js`.
- Все размеры/цвета графиков — из конфига, дефолты ниже.
- Числа форматировать функцией-хелпером, локаль `ru-RU` не использовать для парсинга.
- Кодировка файлов: UTF-8 без BOM, переводы строк CRLF или LF — не важно.
- Комментарии — по-русски, коротко.

## Контракт `chart.js` → `window.ChartKit`

```js
ChartKit.line(container, cfg) -> chart
ChartKit.phase3d(container, cfg) -> chart
```

`container` — DOM-элемент (не jQuery). Canvas создаёт модуль сам, занимает 100% ширины и
`cfg.height` px (по умолчанию 380). HiDPI (devicePixelRatio), `ResizeObserver` на контейнер,
при изменении размера — перерисовка без анимации.

### `ChartKit.line`

```js
{
  height: 380,
  xLabel: 't', yLabel: 'значение',
  xFormat: (v) => String(v), yFormat: (v) => v.toFixed(2),
  series: [
    { name: 'xₜ', color: '#2563eb', data: [[0, 1.2], [1, 2.3]],
      kind: 'line'|'area'|'scatter',   // 'area' = линия + полупрозрачная заливка до нуля
      width: 2.6, dash: null| [6,4], markers: false|true,
      fillOpacity: 0.14,
      smooth: true|false               // сглаживание Catmull-Rom, дефолт true для line
    }
  ],
  yZero: true,          // включать 0 в диапазон Y (дефолт false)
  animate: true,        // анимация прорисовки 450 мс, easeOutCubic
  legend: true,         // интерактивная легенда сверху (клик — скрыть серию)
  tooltip: true,        // при наведении: вертикальная линия + значения всех серий
  grid: { x: true, y: true },
  emptyText: 'Нет данных для отображения'
}
```

Возвращает объект:

```js
{
  update(cfg),        // частичное обновление, перерисовка (анимация только при animate)
  destroy(),          // снять ResizeObserver и обработчики, удалить canvas
  toDataURL(),        // PNG dataURL (для кнопки «Скачать график»), белый фон
  resize(),           // форсировать перерисовку
  setSeriesVisible(i, bool)
}
```

Требования к качеству отрисовки:
- «Красивые» деления осей: 5–7 тиков, круглые числа (1/2/5×10ⁿ), подписи не наезжают.
- Плавные линии (`smooth`), мягкие тени/градиент под линией для `area`.
- Тултип — скруглённая белая карточка с тенью, заголовок `t = 12`, строки «цвет-точка имя значение».
- Легенда — пилюли с цветной точкой; клик скрывает/показывает серию.
- Аккуратные отступы под подписи, без обрезки текста. Оси и сетка очень светлые.
- Никаких внешних шрифтов/картинок. Всё рисуется на canvas.

### `ChartKit.phase3d`

```js
{
  points: [[x,y,z], ...],      // траектория
  labels: { x:'x', y:'y', z:'z' },
  height: 460,
  autoRotate: true,             // медленное вращение, пауза при перетаскивании
  animate: true,
  colorFrom: '#38bdf8', colorTo: '#1d4ed8',   // градиент по времени
  axes: true,                   // рамка-параллелепипед с подписями и делениями
  tooltip: false
}
```

3D-проекция (перспектива/изометрия), точки сортируются по глубине, связываются линией;
drag мышью — вращение, колесо — масштаб. Возвращает `{update, destroy, toDataURL, resize}`.

## Контракт `io.js` → `window.DataIO`

Все функции чтения возвращают объект:

```js
{
  headers: ['x','y','z'] | null,          // имена колонок, если были в файле
  columns: [{ name: 'x', values: [1,2,3] }, ...],  // только числовые колонки
  skipped: 0,                             // сколько строк не распознано
  warnings: ['...']                       // предупреждения для UI
}
```

```js
DataIO.parseText(text) -> parsed            // .txt/.csv/.tsv, синхронно
DataIO.parseXlsx(arrayBuffer) -> Promise<parsed>
DataIO.parseCsv(text) -> parsed             // синоним parseText для CSV
DataIO.readFile(File) -> Promise<parsed>    // по расширению: xlsx/xlsm -> parseXlsx, иначе текст
DataIO.normalizeSeries(parsed) -> { x:[], y:[], z:[], index:[], name, warnings:[] }
DataIO.exportTxt(dataset) -> Blob
DataIO.exportCsv(dataset) -> Blob
DataIO.exportXlsx(dataset) -> Blob          // валидный .xlsx, открывается в Excel/LibreOffice
DataIO.download(blob, filename) -> void
```

`dataset` для экспорта:

```js
{ headers: ['t','x','y','z'], columns: [{name:'t', values:[]}, {name:'x', values:[]}, ...] }
```

Правила парсинга:
- Разделитель: `;`, таб, запятая или пробелы (автоопределение по строке).
- Десятичная запятая: если разделитель — `;` или таб, то `1,23` читается как 1.23.
- Строки-заголовки (нечисловые) пропускаются, но если в первой непустой строке есть
  `x`, `y`, `z` (регистр не важен; допускаются `xt`, `x_t`, `x[t]`, `y_t`, `z_t`), они
  становятся `headers` и используются для привязки колонок.
- Допускаются строки с индексом времени `t`: если есть колонка `t`/`time`/`n` — использовать
  как ось X; иначе ось X = 0..n-1.
- Мусорные строки (текст без чисел) игнорируются со счётчиком `skipped`.
- В `normalizeSeries`: 1 колонка → x; 2 → x,y; 3+ → x,y,z; если 4 колонки и первая —
  монотонный индекс 1..N или заголовок t/time, первая становится осью X.

Правила экспорта:
- TXT: числа через таб, шапка `t x y z`, 6 знаков после запятой.
- CSV: разделитель `;`, десятичная запятая (для Excel RU), шапка `t;x;y;z`.
- XLSX: один лист «Данные», первая строка — шапка, числа обычные (точка).
  Реализация ZIP: центральный каталог + локальные заголовки, метод STORE (0),
  корректный CRC32. Файл обязан проходить проверку (см. самопроверку).

Чтение XLSX — без библиотек: разобрать ZIP (local/central directory), при
необходимости распаковать `DecompressionStream('deflate-raw')`, прочитать
`xl/workbook.xml`, `xl/_rels/workbook.xml.rels`, `xl/worksheets/sheet1.xml`,
`xl/sharedStrings.xml`. Поддержать `<c t="s">` (shared), `<c t="inlineStr">`,
`<c t="str">`, числовые. Если браузер не умеет `DecompressionStream` — вернуть
`Promise.reject(new Error('Браузер не поддерживает чтение XLSX'))`.

## Что от Lead — index.html / main.css / main.js (для сведения)

- Вкладки: **«Временные ряды»**, **«Система Лоренца»**, **«Справка»**.
- Модели `x_t`, `y_t`, `z_t`: изначально показана только `x_t`; если в формуле
  появляется ссылка на `y` — автоматически открывается модель `y_t`, на `z` — `z_t`.
  Плюс кнопки ручного добавления модели. Коэффициенты: x → `a0,a1,...`, y → `b0,b1,...`,
  z → `c0,c1,...`; переменные — `x[t]`, `x[t-1]`, `y[t-1]`, `z[t-2]`, `t`, `wt`.
- Органы управления: N, δW (шум), x0/y0/z0, кнопки «Загрузить», «Рассчитать»,
  «Сгенерировать», «Сохранить как» (TXT/CSV/XLSX).
- МНК-оценка коэффициентов по загруженным данным — в main.js, для каждой модели.
- Метрики MAE/RMSE/MAPE/R², таблица данных, график временных рядов, фазовый портрет.
- Лоренц: RK4 в `rk.js`, параметры σ, ρ, β, dt, tmax, начальные условия; графики
  аттрактора (phase3d) и временных рядов (line).
- «Справка»: описание методов (МНК, Рунге–Кутта 4 порядка, Лоренц, дискретные AR-модели),
  формат файлов, примеры формул.

## Порядок работы команды

1. Lead пишет SPEC.md (готово), создаёт задачи.
2. chart-dev делает `chart.js` + `_tests/chart.html`; io-dev делает `io.js` + `_tests/*`.
3. Lead параллельно пишет `index.html`, `main.css`, `rk.js`, `main.js`.
4. Lead интегрирует, открывает в Chrome headless, делает скриншоты, правит дизайн.
5. Любые изменения API — только через сообщение Lead с обновлением SPEC.md.
