# Стохастические временные ряды

Учебная программа для моделирования случайных временных рядов, оценки
коэффициентов методом наименьших квадратов (МНК) и решения систем
дифференциальных уравнений методом Рунге–Кутта 4-го порядка — включая
классическую модель Лоренца.

Работает в браузере без сборки и без интернета: откройте `index.html`
двойным щелчком (или перетащите файл в окно браузера). Все вычисления и
графики выполняются локально.

![Интерфейс программы](docs/screenshot-series.png)

## Что умеет

### Вкладка «Временные ряды»

- **До трёх моделей одновременно**: `xₜ`, `yₜ`, `zₜ` — авторегрессионные
  уравнения со случайным шумом `δW`. Вначале показана только модель `xₜ`;
  как только в формуле появляется ссылка на `y` или `z`, соответствующая
  модель открывается автоматически. Есть и кнопки «Добавить yₜ / zₜ».
- **Своя формула** для каждого уравнения: `x[t]`, `x[t-1]`, `x[t-2]`, `t`,
  коэффициенты `a₀, a₁, …` (для `x`), `b₀, b₁, …` (для `y`),
  `c₀, c₁, …` (для `z`), шум `wt`.
- **МНК**: коэффициенты оцениваются по загруженным или сгенерированным
  данным; в таблице коэффициентов видно теоретическое значение, оценку и
  отклонение. Оценённая модель рисуется пунктиром.
- **Метрики качества**: MAE, RMSE, MAPE, R² — отдельно по каждой модели.
- **Графики**: динамика рядов (теория, МНК, загруженные данные),
  фазовый портрет (x–y / x–z / y–z, а при одной модели — портрет
  запаздывания), интерактивная легенда, подсказки при наведении,
  экспорт графика в PNG.
- **Данные**: загрузка TXT / CSV / XLSX (перетащить в окно или выбрать),
  сохранение в TXT / CSV / XLSX, копия таблицы, регулируемая длина ряда
  `N`, шум `δWₓ, δWᵧ, δW𝓏`, начальные условия `x₀, y₀, z₀`, зерно
  генератора для воспроизводимых результатов.

### Вкладка «Система Лоренца»

![Странный аттрактор Лоренца](docs/screenshot-lorenz.png)

- Готовые системы: **Лоренц**, **Рёсслер**, **Ван дер Поля** и **своя
  система** (можно ввести до трёх уравнений `dx/dt, dy/dt, dz/dt`).
- Параметры σ, ρ, β (или α, β, γ, μ — в зависимости от системы), время
  расчёта `T`, шаг `dt`, начальные условия.
- Интеграторы: **Рунге–Кутта 4-го порядка** и **Эйлер** (для сравнения).
- Трёхмерный аттрактор с вращением мышью, масштабированием колесом и
  авто-вращением; временные ряды решения; фазовый портрет x–y.
- Сохранение решения в TXT / CSV / XLSX, экспорт аттрактора в PNG.
- Индикаторы: число шагов, фактический шаг, метод, время расчёта.

### Вкладка «Справка»

Краткая теория: дискретные модели и МНК, формулы Рунге–Кутта, система
Лоренца, форматы файлов и обозначения серий.

## Форматы файлов

**TXT / CSV.** Числа через пробел, запятую или `;`; допустима шапка
`x;y;z` или `t;x;y;z`. Колонки:

- одна колонка → ряд `x`;
- две → `x, y`;
- три → `x, y, z`;
- четыре с `t` / `time` / `n` или монотонным индексом → первая колонка
  становится осью времени.

Мусорные строки пропускаются, о них сообщается в уведомлении.
Поддерживается десятичная запятая (при разделителе `;` или табуляции),
кодировка UTF-8 и windows-1251.

**XLSX.** Читается первый лист книги; ячейки с числами. Экспорт создаёт
валидный `.xlsx`, который открывается в Excel и LibreOffice. Старый
бинарный формат `.xls` не поддерживается — сохраните книгу как `.xlsx`.

Пример данных (`_tests/fixtures/data.csv`):

```
t;x;y;z
0;1,24;0,53;0,11
1;1,31;0,61;0,14
2;1,18;0,58;0,19
```

## Тестовые данные

В папке `data/` лежит готовый ряд из 122 точек по трём моделям (три
колонки `x, y, z` плюс ось `t`), сгенерированный с шумом δW = 0,8:

| Файл | Формат |
|---|---|
| `data/test_ryad_122.txt` | текст, числа через табуляцию, шапка `t x y z` |
| `data/test_ryad_122.csv` | CSV для Excel (разделитель `;`, десятичная запятая) |
| `data/test_ryad_122.xlsx` | книга Excel, лист «Данные» |

Данные построены по формулам

```
xₜ = 1,2 + 0,85·xₜ₋₁ + 0,15·yₜ₋₁ + δWₓ
yₜ = 0,4 + 0,30·xₜ₋₁ + 0,60·yₜ₋₁ + δWᵧ
zₜ = 0,2 + 0,30·yₜ₋₁ + 0,50·zₜ₋₁ + δW𝓏
```

поэтому на них удобно проверять МНК: загрузите файл, впишите в уравнение
`xₜ` формулу `a0 + a1*x[t-1] + a2*y[t-1] + wt`, добавьте модель `yₜ`
(`b0 + b1*x[t-1] + b2*y[t-1] + wt`) и `zₜ`
(`c0 + c1*y[t-1] + c2*z[t-1] + wt`), нажмите «Рассчитать» — оценки должны
оказаться близки к коэффициентам выше.

Пересоздать файлы: `node _tests/make_test_data.js`.

## Структура проекта

| Файл | Назначение |
|---|---|
| `index.html` | разметка: три вкладки, панели, формы |
| `main.css` | оформление (сине-голубая палитра, белые карточки, адаптивность) |
| `main.js` | логика моделей, МНК, метрики, связка модулей |
| `chart.js` | собственный движок графиков на canvas (`ChartKit`): линии, области, 3D-аттрактор |
| `io.js` | чтение и запись TXT/CSV/XLSX без внешних библиотек (`DataIO`) |
| `rk.js` | Рунге–Кутта, Эйлер, системы ОДУ, пресеты (`Numeric`) |
| `data/` | тестовые данные: TXT, CSV, XLSX (122 точки, 3 модели) |
| `_legacy/` | исходная версия программы (для сравнения) |
| `_tests/` | самопроверки и скрипты проверки |
| `SPEC.md` | техническое задание и контракты модулей |

Сторонние библиотеки не используются: jQuery и flot из старой версии
больше не подключаются (файлы оставлены в папке).

## Проверки

```powershell
cd MK-main
node --check chart.js
node --check io.js
node --check rk.js
node --check main.js
node _tests/io.test.js        # 37 тестов чтения/записи данных
node _tests/browser-check.js  # headless Chrome: скриншоты и ошибки консоли
```

`browser-check.js` требует установленный Chrome (путь можно задать
переменной окружения `CHROME_PATH`). Скриншоты сохраняются в
`../.tmp/shots`.

## Как это связано с теорией

Дискретная авторегрессионная модель

```
xₜ = a₀ + a₁·xₜ₋₁ + a₂·yₜ₋₁ + δWₓ
```

является простейшей дискретизацией стохастического дифференциального
уравнения `dx/dt = f(x) + w`. Метод Рунге–Кутта 4-го порядка решает уже
непрерывную систему, а модель Лоренца показывает, как из полностью
детерминированных уравнений возникает хаотическая траектория —
странный аттрактор.
