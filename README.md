Что добавлено и изменено
1. Поддержка нескольких моделей одновременно
Раньше можно было задать только одну формулу. Теперь — две независимые модели, каждая со своей формулой, коэффициентами (теоретическими и расчётными), параметрами N, Wₜ, X₀ и графиком.

Модель 1 — фиолетовая.

Модель 2 — оранжевая.

Обе модели считаются одновременно на одних и тех же эмпирических данных.

2. Кнопка переноса расчётных коэффициентов в теоретические
Раньше расчётные коэффициенты (полученные методом наименьших квадратов) приходилось вручную копировать в поля теоретических коэффициентов — чтобы построить график по найденным значениям.

Теперь в каждой панели коэффициентов есть две кнопки:

«→ Перенести расчётные в теоретические» — одной кнопкой подставляет МНК-коэффициенты в теоретические (с округлением до 4 знаков) и сразу перестраивает график и метрики.

«Сбросить теоретические» — обнуляет теоретические коэффициенты.

3. Сравнение моделей
Добавлен общий график сравнения, на котором одновременно отображаются:

эмпирические данные (чёрные точки),

теоретическая и расчётная (МНК) кривые для каждой модели,

разные цвета для разных моделей, пунктир для МНК-кривых.

Это позволяет визуально оценить, какая из моделей лучше описывает данные.

4. Метрики качества
Добавлена таблица метрик качества для каждой модели и каждого типа (теоретическая / МНК):

Метрика	Что показывает
MSE	Среднеквадратичная ошибка
MAE	Средняя абсолютная ошибка
R²	Коэффициент детерминации
MAPE, %	Средняя абсолютная процентная ошибка
Строки с лучшим R² подсвечиваются зелёным и помечаются ★.

Под таблицей — расшифровка аббревиатур.

При наведении на заголовки столбцов появляются всплывающие подсказки.

5. Сворачивание блоков интерфейса
Все крупные блоки можно скрывать тумблерами (справа от заголовка), чтобы не загромождать экран:

Модель 2,

Сравнение моделей,

Метрики качества,

Данные для расчёта,

Расчётные данные каждой модели.

Тумблеры работают независимо, состояние не сбрасывается при пересчёте.

6. Разделение данных и моделей
Поле «Данные для расчёта коэффициентов» теперь общее для обеих моделей — это позволяет честно сравнивать модели на одних и тех же данных.

У каждой модели — свои поля N, Wₜ, X₀ и свой набор коэффициентов.
